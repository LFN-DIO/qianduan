      PIPELINE

      一次分析的完整路径

      1. 01
        APK 安全校验

        验证扩展名、文件头与大小，文件仅写入隔离临时目录。

      2. 02
        静态特征提取

        Androguard 解析 Manifest 与 DEX，不安装、不执行样本。

      3. 03
        训练特征对齐

        按训练阶段的 260 个字段顺序生成向量并应用标准化参数。

      4. 04
        模型推理与报告

        输出良性/恶意概率，同时汇总用户可读的安全证据。

      SAFE USE

      使用边界

      • 模型结论用于辅助研判，不替代人工审核。
      • 混淆、加固与动态加载代码可能降低静态分析完整度。
      • 概率高不代表已确认恶意，仍需结合来源和动态行为。
      • 样本只在本地解析，不会通过网络上传或执行。
